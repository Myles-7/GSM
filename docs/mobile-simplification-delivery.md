## 本轮结果

- 仓库仅保留关键词搜索、分类与排序。高级筛选、保存筛选、AI 整理/分类建议、版本页签从手机移除；历史数据仍保留。
- 仓库概览优先阅读。人工分类、标签、笔记、锁定放在“编辑资料”；编辑草稿跨面板关闭及同页返回保留，远端版本改变时禁止旧表单覆盖。批量手工编辑、摘要和分析收进菜单。
- AI 主入口统一为“AI 分析”，默认详情并更新有效摘要，重新分析放菜单。缺失、空值、纯“未知”字段与整组空标题隐藏，负面事实及有效的 0/false 保留。依据默认折叠，仅来源链接和生成时间；移除普通页面的原始 JSON 与详细证据摘录。
- 阅读工具只留目录和字号；代码复制保留。研究项目、需求、候选、比较、提案完整保留，调整重复标题和布局。提案字段及子分类改用普通表单编辑，保留版本和锁定检查。
- 发现移除 X、Telegram 和代码搜索及来源管理入口，保留桌面配置；周刊进入“更多”。保留趋势历史，中文主题快捷、自定义频道生成/恢复/历史和最近浏览。
- 发现卡片显示多行项目用途摘要、少量标签与 Star。AI 按钮先打开详情，按需分析；“加入研究”是更多操作。未收藏项目的摘要和完整分析以同步消息快照保留，不自动 Star 或加入收藏。
- 热门发布读取实际公开 Release 的版本、发布时间和发布说明。最受欢迎采用后端固定浏览批次，追加去重、已有内容与次序不重排，记录当前频道、游标及阅读锚点；主动刷新才创建新批次。
- 频道切换恢复等待列表真正完成渲染，避免短列表高度截断滚动目标；返回或选中其他仓库后旧详情请求失效。顶部频道栏吸顶，刷新等控件保留明确文字和至少 44px 点击区域。
- 设置保留分组结构，备份和缓存进入“高级数据管理”。清理/导入、离线队列、同步冲突及敏感凭据边界继续沿用原机制。
