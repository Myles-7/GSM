## 3. 数据与协议契约

### 仓库身份

- 新记录使用真实 GitHub ID，拒绝无效 ID；真实 ID 优先于名称。
- 历史名称匹配仅是 best-effort 候选。单一同名候选也不证明原仓库身份；需已有真实身份/可核实证据或明确人工确认，否则保留候选与冲突。
- dry-run 按账号/工作区生成映射与参与存储清单，验证目标碰撞、输入指纹、tombstone、离线和未确认操作后再执行。
- 日志持久化映射、参与存储、阶段与完成步骤；各数据库事务独立，不宣称跨库 ACID。重启续跑前复核同一账号与映射。
- 只改可变仓库引用，不改 Release 自身 ID、分类 ID、不可变聊天/提案历史证据。
- Home canonical 为权威；服务器持久化确认映射，拒绝旧 ID 重建。未知/迟到写入进入明确冲突或升级提示。
- 未确认操作先保持原 payload/opId 完成确认，不改写后直接重发。丢 ACK 时原操作去重确认必须仍可完成。

### 外部源与共享同步

- `external:` namespace；保留 sourceUrl/sourceKind；扩展现有发现配置投影，不搬迁 AI Custom Discovery。
- 每账号最多 10 个源、每源每次最多 30 个仓库、响应最多 128,000 bytes、15 秒。URL 为公开 HTTPS；直连 credentials omit、不带 GitHub Token；初版拒绝自动重定向。
- 取消贯通请求和响应体、详情获取与账号切换；旧账号结果不得写入当前配置。
- Home 往返保留新字段及删除语义；旧客户端不能通过局部投影清空新字段或重建已删源。
- 共享 JSON 兼容修改不空升数据库版本；确有新表才追加 forward migration，不改历史 migrations。

### 插件

- 宿主→页面精确 origin；页面→宿主结合 event 来源、页面身份、插件身份与 session 校验。
- 普通请求 1 MiB，binary JSON/base64 请求 10 MiB，统一 UTF-8 bytes，不能用 JS string.length 代替。
- 关闭、导航、账号切换、禁用/卸载撤销会话；旧 README/AI 响应不再投递。防重放、防跨插件请求。
- 保留既有 AI 出站确认、任务日志、凭据隔离与示例 HTML 净化；复制图片/保存文件通过明确宿主权限。

### 向量与质量

- 徽标是本地可确认待处理数，不是假定的精确待写入数：未索引、身份/代际失配、已知变更。
- 独立保留扫描候选数；完整内容哈希比较仍在用户启动索引后执行。徽标不触发 README、AI 或付费请求。
- 允许显式声明选定功能必需的运行依赖，但不移动前端依赖以瘦身。
- 保持桌面 origin、userData 和应用身份；只在隔离副本验收，不提前迁移原数据。

## 4. 验收矩阵

| 类别 | 必测场景 |
| --- | --- |
| 身份/数据 | synthetic ID、rename/旧名复用、多账号、人工清空/锁定、跨库引用、tombstone、离线操作、丢 ACK、重启续跑、共同恢复 |
| 导入/Release | 历史复用、账号取消、权限/限流分类、源码后缀、显式源码、正文链接、跨过滤器 OR、显示全部重置 |
| 外部源 | JSON/RSS/Atom、大小/数量/时间预算、Token/凭据隔离、重定向拒绝、读 body 取消、账号切换、删除与 Home 配置往返 |
| 插件 | 来源隔离、会话撤销、重放/跨插件、UTF-8/binary 预算、AI 确认/日志、复制图片/保存文件、信息卡净化 |
| 个人能力 | Workbench、Organization、AGY、HTML Reading、Custom Discovery、整页翻译、Home、现有桌面启动入口 |
| 工程 | 类型、分层、多语言、插件注册、向量产物、前后端相关测试、真实 Electron；记录未触及 lint 基线，不声称全仓库全绿 |

恢复点验证必须同时包含源码 bundle 和数据一致性校验。SQLite 在线服务使用 Backup API 的一致快照，单纯复制运行中的 db/WAL 文件不作为唯一恢复证据。Electron 数据在正常退出后冷备份。

## 5. 来源与完成规则

upstream-base.json 按项记录来源标签/SHA、实际吸收范围、排除原因、个人提交、数据版本、验收证据。准备阶段只登记 pending 批次，最终通过后才变更已验证个人版本。

不合并整个 v0.8.5 标签，不伪造完整消费基线。下一次升级同时检查真实 Git 基线、选择性消费记录，以及此前排除的 #412/#413、浏览器/后端 WebDAV 等未迁移项。

目标不是让所有上游文件相同，而是保持明确的选定行为、数据不变量和个人能力。任何阶段未完成的退出条件必须如实标记，不通过标签或版本记录掩盖。
