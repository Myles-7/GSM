# 手机 HTML 阅读打磨交付

日期：2026-10-04。依据用户九项逐题决策实施，详情见 html-reading-mobile-polish-decisions-20261004.md。

## 修改结果

- 顶部合并为两行：页面名、搜索、更多、轻量导出；当前频道或分类、期刊日期和项目数量。完整频道在抽屉中切换，去掉横滑频道与重复的列表标题。数量入口仍可选择阅读视图，搜索及筛选标签按需显示。
- 期刊改为网页内底部面板，日期、数量、状态分列，选中项有高亮和勾选。隐藏 0 项期刊，信息面板保留缺失日期及原因；部分完成的可读期刊显示“部分内容”。全部为空时保留频道和原因，不伪造结果。稳定期刊 ID 与历史资料没有删除。
- 卡片只标明桌面已知“已 Star”，数量仍按原导出配置展示。详情信息说明状态与桌面记录时间；不在收藏记录中按未知处理，不推断未 Star。已 Star 项目的候选位置为只读标记，不自动清除原候选或回传记录，不新增 GitHub 查询。
- 阅读操作仍在正文末尾，四等分单行，图标配合“已读／兴趣／忽略／候选”短文字；未读状态对应显示“未读”。选中底色和完整无障碍操作名称保留，最小点击高度 44px。
- 笔记按需展开；无笔记显示添加入口，有笔记显示短预览，完整内容在编辑器中查看。输入、失焦、导出和退出保存继续保留，折叠不会截断回传中的笔记。
- 详情顶部只显示项目名，单行省略长标题。操作菜单中的项目信息可查看并复制完整所属者／项目名；复制失败可手动选择原文。

未改变完整摘要、结构化分析、正文默认字号、正文末尾操作位置、账户隔离、邮件配置与 v1／v2 回传协议。该轮仅升级每日 HTML 生成器，没有 APK。

## 验证与证据

专项前端测试 214 项和 Electron 测试 37 项通过；新增覆盖当前账户的已知 Star、发现项目未知状态、只读候选、原候选记录不被清除、按需笔记、隐藏空期刊与全部空频道。

全项目类型检查、修改文件 ESLint、依赖边界、包体预算和生产 Vite 构建通过，项目根目录 dist 已更新。

使用实际生成 HTML 和模拟工作区完成浏览器检查：360／390／430／768／1024px，明暗主题、16／20px 阅读字号、期刊面板和四按钮单行、横向溢出、详情与期刊返回、完整名称、未知状态说明、笔记关闭重开及 v2 回传。另通过现有阅读闭环浏览器回归，包括 5,000 仓库、最多 120 张挂载卡片、搜索、正文目录和累计导出。

同一份快照在 390px 浏览器内容视口的对比：旧发现页首卡片顶部为 209 CSS px，新版为 99 CSS px；固定头部为 93 → 91 CSS px。减少的是重复列表标题与期刊整行占用，未截断摘要。测量不包含手机系统状态栏和附件查看器。

## 在当前桌面使用

完全退出 GSM（包括托盘）后重新打开，从设置 → 每日 HTML 重新预览、导出或生成附件。当前电脑使用根目录启动方式，无需重新安装此前 ZIP。

旧 HTML 文件不会自动升级。若旧文件仍有修改，先导出并导入桌面，再生成新文件；各文件本地记录继续独立保存。新文件中 Star 状态来自生成时的桌面已知记录，不是实时 GitHub 状态，需更准确时先在桌面更新收藏资料。
