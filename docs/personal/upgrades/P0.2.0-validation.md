## 边界与剩余限制

- 浏览器外部 feed 仍需服务端 CORS；客户端 HTTPS/主机名校验不能证明 DNS 解析结果或阻止 DNS rebinding。不增加代理。
- 已开始的远端 Star、文件写入或向量写入可能在取消后完成；取消不是撤销。未知结果不自动重试。
- 向量徽标只表示本地可确认待处理数；远端真实内容哈希比较仍在用户启动索引后执行。
- 原数据迁移、真实 provider/AGY 执行、远端 Worker 部署、安装包、跨平台发布及自动更新不是本次自动验收动作。
- 选择性来源、个人提交和未吸收项必须保留；下一次升级不能把本次视为完整 v0.8.5 merge。
