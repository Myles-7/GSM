## Issues Found And Corrected

- Interrupted Viewer still had opaque-origin messages and wildcard responses.
  Replaced its bridge and bound renderer requests to Node-issued sessions.
- Completed request IDs had not been retained. Both layers now reject replay.
- Async web search released the Node slot at authorization. It now holds the
  slot through execution and validates the session again before replying.
- Existing AI preflight/recheck repeats authorization. Rechecks use fresh
  host-owned IDs without reopening the page ID for replay.
- Account/token comparison alone misses batched A-B-A. README uses a monotonic
  epoch, aborts immediately, and discards late work.
- Consent can remain unresolved after page close. Journal cancellation races
  the waiting operation; stop/close finish promptly, late approval cannot call AI.
- Base64 grouped repetition risked regex stack growth on large exports.
  Linear character validation plus canonical decode/re-encode handles boundaries.
- A negative-only output sanitizer is insufficient for copied standalone HTML.
  Example output now uses positive element/class/attribute allowlists.
- Production manager lacked hostOperations. Main now injects native output.
- Window/frame identity alone trusted hostile documents. Every plugin IPC now
  checks the selected production entry or configured loopback dev origin;
  matching-origin blob documents also fail closed.
- Navigation-start revocation alone allowed the unloading document to reopen.
  The registrar suspends main-document IPC until the next dom-ready.
- Actual installed Electron 44 removed writeImage and made clipboard writes
  asynchronous. The adapter now supports ClipboardItem PNG writes and awaits
  completion while retaining the older API path; a red/green regression covers it.
- Clipboard images now require PNG signature and IHDR validation before native
  decoding. Both header and decoded sizes obey 8192-side / 32,000,000-pixel limits.
  The red/green regression asserts oversized or malformed headers never call the
  decoder; boundary acceptance and decoded-image rejection remain covered.
- App startup mock lacked subscribe. Added real listener/unsubscribe semantics
  and an account-change revocation regression, without weakening production.
- Full-suite README boundary timed out while resetting unrelated plugin module
  dependencies; a subsequent test could inherit its DOM. Isolated those unrelated
  plugin dependencies and added explicit cleanup, but a later full run reproduced
  the timeout. The async cold Card import inside a timed test could continue
  rendering after timeout/cleanup. Success and chunk-load rejection now have
  separate static-import module graphs, with no per-test resetModules. Real lazy
  imports remain deferred and asserted; focus, ErrorBoundary and timeout values
  are unchanged. Full parallel-suite verification is delegated to the main owner.
- The shipped repo-health-page lacked request payload origin. It now sends its
  exact page origin, pins the observed host origin and clears stale requests on
  session replacement/page close; wrong-source/origin/identity/token/ID and
  successful migration regressions passed.
- Native fixture originally observed stale "Copied" status from the previous
  operation and could restore while PNG copy was still pending. It now waits
  for completed production IPC before checking physical output or restoring.

## Integration Gaps And Residual Risks

- App/card and production main integration are now verified. No locale patch or
  further plugin integration API change is needed. DAV registration was unchanged.
- Interactive native save dialog, live provider,
  AGY execution, remote vector indexing and production packaging remain unverified.
  Do not confuse the fake-host page probe with the separate actual-main App probe.
- Older handwritten plugin pages lacking payload origin intentionally fail closed.
  The shipped repo-health-page has now been explicitly authorized and migrated.
- Clipboard snapshot/restore checks do not provide an OS-level compare-and-swap;
  an external change between the final read and atomic write cannot be excluded.
  Unknown formats are not overwritten, and detected changes fail acceptance.
- Existing feature hooks are outside this worker's scope. The Viewer imports the
  session-aware hooks under src/plugins; unbound legacy capability calls fail closed.
  Future consolidation of the two hook locations should preserve this consent,
  cancellation and journal contract, not restore unbound calls.
- A filesystem write that has already begun may complete after revoke. No automatic
  retry is provided; suppressing a late success is not proof that nothing was written.
- Snapshot limits bound retained data, not the raw IPC object's transient memory.
  Generated information still requires factual review before sharing.
