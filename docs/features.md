# 核心功能约定

## 仓库库与分类

同步 Stars 后按关键词、语言、标签、平台、分类和分析状态筛选。用途与技术分类各自保留结构和导航；切换不改变仓库 GitHub 身份。人工分类、锁定、证据与 AI 推断分别保留。

分析生成摘要与结构化资料，整理建立结构并分批归类。用户明确应用前，提案不能改写资料；锁定、身份变化、冲突和部分失败需要可见反馈。供应商执行成功与结果保存成功分开记录。

地图探索把资料组织为主题、实体与关系。直接支持、有据互通、同类能力和探索建议不能混为一类；未验证推断不能展示为已证实事实。已有探索与中断任务可恢复。

搜索或选择分类时退出相似项目视图，避免结果来源与导航不一致。空结果、服务未配置、离线与供应商错误需要可见反馈。

## AI 工作台与任务

仓库问答固定到读取的提交，以文件范围和来源引用支撑结论；没有证据保留未知，不编造部署命令。AGY 本地研究仅使用用户选择的目录授权，取消、关闭会话或身份变化后停止使用授权。

任务中心展示阶段、请求、部分响应、错误与落盘结果。重试沿用成功结果；超时不代表供应商肯定未执行，不自动无限重试或重复发送回执不明的副作用操作。

AGY 模型出现在列表中，不代表该模型当前有服务容量。`SERVICE_UNAVAILABLE` 表示模型服务暂不可用（例如 503 或容量不足），应稍后手动重试，或自行选择其他模型／推理强度并执行“保存并测试”。不同模型与强度组合分别验证；GSM 不会自动切换模型，也不会把错误结果中附带的文本当作成功回答。已经发送的失败请求仍可能产生用量，恢复记录保留未知状态。

AGY 恢复区按账号限制为 50 MiB，执行中的调用各预留 8 MiB；返回成功后改按加密结果的实际大小计量，保存检查点时原子核算新增空间。启动时自动纠正旧成功记录的整块预留，不删除、解密或确认消费其结果。真正达到额度时仍停止新调用，需在任务中心处理已有结果。

项目地图的深入探索分批保存，继续任务会复用已完成项目。远程资料按探索主题提取原文片段，每项目最多发送 8,000 字符的远程资料，引用仍须对应所提供原文。模型服务不可用时停止派发新批次，已发出的其他批次独立保存；任务中心区分本次批次与累计项目检查点，并直接显示阻塞原因。

探索缓存按语言、模型、推理强度、供应商地址和分析版本区分；同一方向使用当前选中的缓存，不叠加不同模型或语言的结论。强制重新分析刷新资料并重建结果，继续中断任务保留已完成批次。旧版地图缺少分析身份，用户下次主动更新地图时重新分析一次；已有历史与人工调整保留。原文引用匹配只能确认出处，关系仍是 AI 判断，不能视为独立事实核验。

HTTP 文本、流式和工具请求均受十分钟上限及调用方取消约束，已发送请求的超时仍记录为结果未知。限流等待遵守服务端完整 `Retry-After`，长等待可取消。代理只有明确返回 `404 / AI_CONFIG_NOT_FOUND` 才使用内联配置。模型、Embedding 与向量 Worker 的直连凭据请求仅允许 HTTPS 或本机 HTTP，并禁止自动重定向。

## Releases、发现与插件

Release 时间线支持订阅、已读、平台/文件过滤和浏览器/RPC 下载。发现频道与规则通过任务筛选和保存候选；收藏与订阅是明确的用户操作。见[发现 API](discovery-feed-contract.md)。

插件通过 manifest 声明权限，页面 AI、搜索和本机请求由宿主检查。固定版本与哈希用于分发核对，不能代替对原生插件代码的信任审查。见[插件开发](plugins/v1-development.md)。

## 离线 HTML 阅读

桌面从同账户资料生成单文件 HTML，不携带 token、邮箱授权或本机路径。正文、样式和阅读脚本内置，外部来源通过链接打开；字段、频道、邮件与文件体积可配置。

手机修改以 JSON 手工回传，按账号、快照、仓库 ID、基础值和唯一操作 ID 校验。冲突保留双方，回执与修改原子落盘，迟到快照不能覆盖新位置。收藏候选另行确认，并再次核对 GitHub ID。

自动邮件要求 GSM 运行且电脑可用；计划时间是开始时间，不保证收件时间。SMTP 回执不明时先查邮箱，不自动重发。本地 HTML 浏览器存储不可靠，关闭前导出修改；真实邮箱与手机仍需实际设备验证。
