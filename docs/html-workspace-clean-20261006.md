# HTML 页面整合与简洁视觉重构 — 2026-10-06

导航及页面标题统一为 **HTML**。桌面页面保留项目、日报、配置三个分区，默认打开项目。原设置中的每日 HTML 入口移除，旧导航请求转到 HTML 配置。

## 实现

- 项目页使用可拖动的列表／详情分栏，按账户记住宽度。列表只呈现名称、所属者、一行用途与必要状态；窄内容区域改为列表／详情返回流程。
- 完整摘要、问题、功能及场景展开；架构、快速开始、部署、成本和维护按稳定栏目 ID 折叠。列表和命令保留 Markdown 结构，缺失栏目不渲染。
- 筛选进入面板，默认显示待处理／已处理。选择模式中显示勾选和批量栏，跨页选择保留；退出明确清空选择。
- 笔记使用独立面板，保留按项目草稿、保存错误和并发修改冲突。任务从紧凑入口打开，关闭任务面板不停止执行。
- 导入使用宽弹窗，导入完成定位本次项目。业务修改、候选确认、版本检查及恢复机制继续使用原实现。
- 日报页集中预览／发送入口，导出、内容检查、历史和补发收进菜单或面板。发送未确认仍要求先检查收件箱；草稿发送仍需选择保存并发送或使用已保存配置。
- 配置分为内容与频道、阅读与手机操作、邮件与定时、高级与存储四组。组间保留草稿，只在修改时显示统一保存条；离开页面可保存、放弃或留下。
- 修复定时服务拒绝保存时磁盘设置已改变的问题：失败后恢复原磁盘配置，并保留表单草稿。
- 修复翻页不重置列表滚动，以及缩放下分栏高度计算错误；预留实际保存条高度。

本轮不修改手机 HTML 的 JSON 协议、邮件调度规则、数据库业务格式或模型选择，不新增 AI 请求，不自动执行真实 Star／测试邮件。旧设置、回执和业务记录兼容；仅浏览状态新增字段并兼容旧值。

### 已知限制

全前端测试失败项为 `src/services/aiOrganizationDualExecution.test.ts` 中 `refuses full retirement when a retained or out-of-scope member remains`。该用例期望 AI 双分类应用拒绝范围外成员仍占用的分类退役，但当前实现没有拒绝。独立重跑该文件得到 8 项通过、1 项失败。本轮没有修改分类应用业务规则来消除这一失败，因此不宣称整个工作区回归全绿，目录包为可审阅构建。

TypeScript 和国际化检查也发现并修正了其他改动中一处测试 `null`／`undefined` 不匹配和静态检查器的翻译命名空间识别问题；其余并行改动保留。真实 Star、真实 Gmail 发送、真实账户切换、系统 DPI 及安卓附件流程本轮未验收。
