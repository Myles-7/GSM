# 每日 HTML 内容自定义与完整阅读

更新：2026-10-03。按本轮十三项选择实施；延续单文件离线阅读、桌面主题、Gmail 附件及北京时间 08:00 调度。没有开发 APK，没有新增模型请求，也没有向真实邮箱发送测试邮件。

## 使用入口

使用更新后的项目桌面构建，打开 **设置 → 每日 HTML**。当前运行的窗口需要重新加载新构建；已经发出的旧 HTML 附件不会自动更新。先把旧文件中的待回传修改导入桌面，再生成新文件。

1. 在“内容范围”选择刷项目或深入阅读预设。两者都保留完整摘要；刷项目默认折叠使用与维护内容，深入阅读默认展开。原始介绍和来源依据默认折叠。
2. 选择仓库范围、数量与频道。仍按当天桌面快照排序，并恢复已回传的阅读位置，不建立额外的轮换队列。
3. 在“阅读样式”调整全局默认内容、字号、密度、明暗和文件上限。
4. 展开仓库高级内容、发现默认内容或具体频道。未单独调整的内容依次继承预设、全局、页面；具体频道最后覆盖发现默认值。高级频道表单按需挂载，不预先加载全部配置控件。
5. 用实际 HTML 预览检查，保存设置。手动预览与导出采用当前表单，定时发送采用已保存的设置。

预设切换遇到高级调整时，必须选择保留、重置或取消。重置只恢复展示配置，保留已经单独设置的数量与历史期数，也不修改范围、字号、邮箱和发送时间。每个配置组可单独恢复继承。

## 内容与外观

- 卡片、详情都保留已有完整摘要，不按字符或行数截断。有 AI 摘要时卡片不重复原始描述；没有摘要时显示原始描述。原始介绍在详情默认折叠。
- 卡片可以选择字段并调整顺序。相邻标签与元数据合并为紧凑行；最多展示三个分类／标签。主题与强调色继续继承桌面。
- 详情栏目支持展开、折叠、不导出，并按概览、使用、维护分区内的配置顺序显示。没有内容的栏目和空页签不会出现。阅读操作区保留独立位置。
- 折叠仍保存完整内容，只有不导出才排除相应字段。若卡片仍选择同一字段，或其他频道仍需要该字段，文件会保存那份共享资料；它不会因此显示在当前视图的详情中。
- 仓库、发现默认和各频道分别配置卡片与详情。频道可以单独限制每期项目数及历史期数；历史仍受回看天数限制。频道上移／下移改变频道顺序，不重排项目。
- 全局提供 14／16／18／20px、紧凑／标准间距，不增加每频道独立的字体或配色设置。
- 旧设置的字号、范围、字段开关、邮箱配置保留；旧摘要字符数与行数字段仅为格式兼容保留，新生成器不再用它们截断内容。

## 手机连续阅读与回传

列表菜单提供全部、未读、感兴趣、收藏候选。它们只过滤当前文件中的项目，不改变导出范围。每个频道／期刊独立保存搜索、分类、阅读视图和位置；关闭重开依赖浏览器可用的本地存储。

详情顶部操作菜单提供上一项／下一项，只沿当前过滤列表顺序移动。进入新项目回到概览开头，返回列表定位当前项目；不会把每次下一项都堆成返回历史。默认打开详情即已读，可在桌面改为手动标记；仅恢复位置不会触发已读。

同一项目在各频道仍会出现，已读、兴趣、候选和笔记共享。详情默认折叠“其他入选频道”，保留各自推荐理由和版本来源。不同频道的推荐理由不会互相覆盖。

回传协议仍使用 v2，并兼容旧 v1。列表阅读视图保存在该文件本机，回传的位置仍是稳定项目锚点；下一份日报按当日完整范围恢复锚点。导入继续执行账户校验、冲突处理、去重和迟到位置保护，候选导入不自动 Star。

## 刷新、数量与超限

仅发送前的内置发现刷新可能联网读取 GitHub；预览、导出、自定义期刊都不触发新的 AI 任务。

内置频道在 90 秒总预算、每频道 30 秒、最多 20 次分页请求及单频道 10 页的限制内继续获取。请求页大小固定，按稳定 ID 去重，保持首次取得顺序；上游结束、缺条件、限流、游标无效或预算耗尽会说明原因，不承诺一定凑满设置数量。

第一页之后失败时保留取得的项目及此前缓存，不把整份混合缓存标为已完整刷新。完全失败时保留原缓存和更新时间。预览区分别显示目标上限、缓存可用数、实际导出数、条目总量、去重项目数与 UTF-8 文件体积。

超过 1–15 MiB 配置上限时停止生成／发送，不自动截断摘要、删项目或拆附件。账户阅读存储保留最近十条超限记录；定时发送失败记录也包含调整说明。减少数量、历史期数或把栏目设为不导出后，可以重新预览、导出或发送。SMTP 接受不等于收件箱实际送达。
