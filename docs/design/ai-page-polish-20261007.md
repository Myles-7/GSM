# AI 页面保留式优化记录（2026-10-07）

## 决策

用户否决了 `ai-page-redesign.html` 中的三栏工作台重构。现行方向是保留原有布局、主题和交互锚点，只修复视觉缺陷并做局部层次优化。

该 HTML 已标记为「已否决 · 归档」，不再作为实现依据。

## 保留不变

- 顶栏、220px 会话栏、结果/对话分栏和常驻输入区的结构。
- 需求编辑器、提案预览、组织面板仍留在消息流中。
- 现有主题、下划线 Tab、用户气泡和紧凑密度。
- `aria-label`、`aria-pressed`、`role`、`data-testid` 与既有文案。
- `useAIWorkbench`、持久化、同步和 store schema 均未改动。

## 已落地

- 分栏断点从 1280px 对齐到 Tailwind `xl` 的 1300px。
- 增加 `border-strong` 颜色别名，暗色用户气泡改用更清晰的边框。
- 输入框、文本域和选择框统一为 3px focus ring。
- 警告与成功色改为主题 token；原生 select 替换为 `WorkbenchSelect`。
- 顶栏改为左、中、右三组，Tab 保持下划线语言并居中。
- 会话行增加已有摘要或运行阶段的第二行；键盘弹出时折叠该行。
- 活跃会话使用主色左缘和浅底，置顶与运行图标使用主色。
- 证据行补齐 hover，提案胶囊去掉持续脉冲。
- 输入区改为卡片容器，意图切换改为胶囊，并保留原按钮语义。
- 桌面端补充 Enter / Shift+Enter 提示。

## 明确未做

- 未把顶栏、侧栏、消息流和输入区拆成独立组件。当前改动集中且行为耦合较深，拆分会扩大回归面，不能带来用户可见收益。
- 未显示「候选数 · 消息数」。列表数据没有按会话加载这些计数，补齐需要改 hook 和存储读取路径，超出本次 View 层边界。
- 未新增 9 语言文案。摘要与快捷键提示复用了现有字段和文案。
