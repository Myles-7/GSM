# 手机 HTML 阅读留白优化

日期：2026-10-03。针对用户提供的安卓截图，减少页面自身的固定工具栏和重复信息。修改的是每日 HTML 生成器，不重新开发 APK。没有改变邮件配置、分析内容选择、回传协议或桌面模型。

## 实际修改

- 搜索默认收起，点击顶部放大镜展开；收起后保留关键词、筛选结果和输入内容。
- 分类／全部频道直接放在顶部工具栏。明暗切换与完整频道说明、更新时间移入信息面板。
- 发现页只在列表顶部保留频道名称与结果数量，不再常驻整段说明和精确更新时间。错误和过期警告仍明确显示。
- 底部仓库／发现改为图标与文字同排，减少纵向占用；列表底部预留空间随之缩小，最后一项不会被导航盖住。
- 详情顶部只保留一次完整仓库名及返回、GitHub入口，取消重复大头像、标题和所属者区域。分析页签固定在详情头部下方，语言、Star、更新日期以一行元数据进入正文。
- 减少段落间和详情底部的额外留白，正文默认16px、卡片摘要行数和内容保持原设置；操作控件至少44px高。
- 打开详情后隐藏列表工具栏和底部导航，返回时恢复原列表锚点与偏移。
- 移除`viewport-fit=cover`，由浏览器使用正常安全视口；样式仍保留`safe-area-inset`保护。系统状态栏和文件查看器自身工具栏无法由HTML移除。实际安卓查看器如何提供安全区仍需用户设备复核，不能声称已从截图验证原因。

## 使用

从托盘退出并重新启动项目内的GSM，然后进入“设置 → 每日HTML”，重新预览或导出。之后生成的每日附件采用本次布局；已经下载的旧HTML是独立文件，不会自动改变。若旧文件中还有未回传修改，先导出并导入桌面，再生成新文件。

实际安卓浏览器、文件查看器的安全区和软键盘行为没有真机验收。本次浏览器检查不能替代用户设备结论。
