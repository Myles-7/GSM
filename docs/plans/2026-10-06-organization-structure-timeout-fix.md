# AI 整理结构生成超时修复

## 已核实问题

退出桌面后读取隔离 profile 副本：最新任务停在 structure，368 项 understood、1 项 insufficient，两个方案均未生成。事实输入约 216448 字符；5 个首层汇总批次各尝试 3 次，共同原因是 AGY_TIMEOUT。不是分类 JSON 校验失败，也不是所有仓库资料读取失败。

现有代码另有两处可复现缺陷：重试在事实全部复用时跳过缺失结构；流水线没有持久保存成功的汇总批次。页面把请求超时合并成连接失败，并因缺少整理专属探测记录显示未就绪，尽管设备已启用且基础探测成功。

## 修复

- 汇总输入按约 8000 字符分块；异常长的单仓事实拆成片段，不丢弃证据。输出明确限制为两个紧凑领域摘要，各至多 1000 字符；不改变模型或推理强度。
- 成功汇总保存输入 SHA-256、层级和批次标识。重试仅复用输入完全匹配的检查点；事实或语言变化使相应检查点失效。旧草案字段仍兼容，无主 Store 版本变化。
- 重试补齐未就绪方案，保留已经成功的另一套分类和人工目标；局部资料核实仍保留既有结构。
- 有限自动重试保持不变；超时独立显示 MODEL_TIMEOUT，旧 CONNECTION_FAILED/AGY_TIMEOUT 记录也给出正确说明。
- 展示资料汇总层级及已保存/总批次；开启状态不再依赖缺失的功能探测记录。重测未修改身份的已启用模型不再先关闭 AGY。
- 整理弹窗可显式修改整理专属超时（20–600 秒）及配置；不自动加长原 180 秒、不自动降级模型。
