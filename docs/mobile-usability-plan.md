# 手机日常使用路径优化

2026-09-30。目标：查看收藏、连续浏览发现、通过 AI 理解和选型。沿用此前 25 项取舍，保留业务资料、离线队列、凭据和桌面功能。本轮使用界面工程和子代理实施技能，将仓库、对话和发现三个独立页面改造后进行统一回归和审阅。

## 当前可复现的问题

1. 固定品牌、同步行、页面标题、频道标题和说明重复，发现首屏进入项目卡片前占用约半屏。
2. 仓库默认概览几乎只显示人工资料，已有完整分析仍需切换页签；项目摘要、详情分析和发现正文重复，无法快速回答“这是什么、适合我吗”。
3. 分享、GitHub、编辑、重新分析与核心阅读操作混排；分析提交后缺少仓库内的连续状态反馈。
4. 发现渠道浏览菜单同时包含配置复选框，日常选择与管理混杂；分页需要反复点按钮，错误状态常远离操作区域。
5. AI 首屏叠加模型、项目选择、候选数量、会话标题和三条研究话术。空输入框需要理解工作台术语，项目或仓库对话仍使用通用话术。
6. 输入操作、最近阅读、返回和滚动恢复在长页面中容易失去上下文；已有竞态保护和固定热门批次必须保留。

## 实施方案

| 路径 | 改造 |
| --- | --- |
| 全局导航 | 单层紧凑顶部，标题随当前页面变化；同步正常时用小状态入口，异常仍明确展示；任务和设置保留。短暂成功提示自动收起，不遮挡长内容。底部三个入口保持不变 |
| 收藏列表 | 搜索、分类、排序紧凑且易触达；列表清楚显示名称、足够说明用途的摘要和少量元数据；没有更新时间不显示“未知”。保留有界分页、批量编辑和分类管理 |
| 仓库阅读 | 默认概览先显示现有分析中的问题、功能和适用场景；完整分析和 README 保留。减少重复摘要与空人工资料块；其他操作进菜单。分析任务原位显示接收、进行、完成/失败和恢复入口，已完成结果立即可读 |
| 发现浏览 | 单行当前频道/选择与常用频道栏，减少横幅；显式搜索快捷入口、刷新与更新信息；频道抽屉只负责选择，配置在设置。保持缓存、游标、位置恢复、取消/竞态保护和上游错误 |
| 连续阅读 | 开启受控近底部增量加载，按 ID 去重，失败时停止自动重试并给重试按钮；保留加载更多作为无 IntersectionObserver 的后备。缓存未刷新、加载和结束状态清楚可见 |
| 项目详情 | 与仓库一致的标题、摘要、主要动作和内容层级；README 进入独立分区，避免分析和全部 README 一起拉成长页。已有摘要优先，按需分析和 Star 确认保留 |
| AI 日常使用 | 空闲首屏直接提问，按仓库/通用场景提供真实示例，候选/项目上下文仅在有内容时出现；完整项目、需求、候选、比较、提案进入明确的“研究工作台”入口。保留草稿、会话、流式恢复和历史阅读不被打断 |

## 验证及发布

检查日常路径的点击数、首屏内容和重复文本；360/390/430/768/1024px 明暗主题、长名称与真实长度中文摘要；5,000 仓库/10,000 消息有界渲染；分析/恢复/空状态/离线与请求乱序；类型、边界、单元和浏览器回归；同应用 ID 和签名的新 APK。

本轮以前端交互为主，不重复尝试上次被 UAC 取消的服务升级。新发布/稳定热门功能依旧按后端能力开关启用。Android 真机未连接时明确记录未验收。
