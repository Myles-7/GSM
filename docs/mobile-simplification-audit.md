# 手机端功能精简审查（待用户决策）

本轮先审查现有代码与已有截图。未进行真机观察或使用频率统计，因此不能把主观判断当成用户实际需求；下面是候选建议，不是已批准的删除方案。

## 已确认的界面与流程问题

| 区域 | 代码/截图观察 | 使用影响 | 候选处理 |
| --- | --- | --- | --- |
| AI 首页 | 模型、工作台标题、模式、项目选择、编辑项目、会话标题同时出现 | 到达输入框前占用大量高度，用户须先理解多个概念 | 将模型与项目收进一个顶部上下文入口，默认直接对话 |
| 发现卡片 | 摘要、软件形态、标签、平台、已有分析状态、分析展开、GitHub topics 同卡展示 | 浏览信息密度与卡片高度同时增加，一屏项目少 | 列表仅保留摘要与少量关键标签；完整分析移到详情 |
| 仓库概览 | 默认展开人工整理表单；AI 助手提供摘要、详情、分类三个按钮 | 阅读与编辑混在一起，新用户不知道先做哪一步 | 阅读优先，编辑进独立面板；统一一个分析主动作 |
| AI 整理 | 仓库页面已有分析/分类/批量整理，AI 页另有整理模式 | 范围和结果入口分散 | 单一整理入口，其他页面跳转同一流程 |
| 分类管理 | 列表分类抽屉和设置都有分类管理 | 浏览分类与修改分类不易区分 | 抽屉只浏览，管理集中在一个入口 |
| 频道管理 | 频道抽屉内显示开关，设置内还有显示与排序 | 选频道时容易误修改两端业务配置 | 抽屉只选择，编辑放管理页 |
| 模型选择 | AI 主页面选择器与 AI 偏好设置重复 | 默认与当前模型概念不清 | 默认放设置，对话顶部仅显示当前模型并按需切换 |
| 任务信息 | 页面内任务面板与独立任务中心重复呈现 | 阅读正文被阶段/状态打断 | 原位只显示简洁状态，详细执行过程进入任务详情 |
| 热门发布 | 后端实际按最近 14 天 pushed 时间查询，并非 Release 数据 | 名称可能造成错误预期 | 改为“最近活跃”，或退出常用频道 |
| 代码搜索 | 需要用户理解 GitHub 搜索语法，显示文件路径与片段 | 手机浏览成本高；适用于明确开发需求 | 低频工具/移除，取决于用户需求 |
| X / Telegram | 当前真实部署 X 缺凭据、Telegram 上游不可达 | 常用界面出现不可用功能，增加困惑 | 不可用时不进入快捷栏；是否保留由用户决定 |
| 原始 JSON | 期刊与部分任务结果保留原始数据折叠入口 | 普通用户难以解释，增加界面层次 | 从普通页面移除；必要诊断另行保留 |
| 最近浏览 | 仓库首页占一段高度 | 对收藏浏览不一定必要 | 移入搜索/历史，或按需求删除入口 |
| 常用筛选 | 可保存与管理复杂条件 | 有重复筛选需求才有收益 | 收入筛选面板；不默认占列表空间 |
| 阅读工具 | 每篇内容上提供目录/查找/顶部/字号 | 短内容工具比正文更突出 | 阅读菜单统一提供，长文按需展开 |
| 设置 | 八组分别包含连接、同步、诊断、管理、数据等 | 首屏路径较多，但包含必要维护能力 | 常用偏好与高级维护分层，不移除恢复保护 |

## 决策原则

1. 区分“功能没有价值”和“入口/交互做得差”。后者优先合并或改布局。
2. 所有删除默认只影响手机入口和流程，不删除桌面功能、已保存资料或数据库记录。
3. 保留连接认证、同步冲突、人工锁定、任务取消/恢复及数据恢复等必要保护；可以简化默认展示。
4. 隐藏不可用渠道必须可解释和恢复，不能用空列表掩盖失败。
5. 调整仓库分析与发现卡片时，保持完整分析与证据可以从详情获得。

## 询问与开发步骤

- 第一轮：主要用途、具体不好用例子、精简程度。
- 第二轮：发现频道取舍、AI 项目与研究是否保留、仓库管理与阅读工具取舍。
- 第三轮：针对争议项给出明确保留/合并/收起/删除列表，确认最终范围。
- 形成可执行方案后开发，验证入口导航、离线队列、历史资料与任务恢复，构建同身份 APK。

## 已确认方向与逐项决策

核心用途：查看收藏仓库、刷发现找感兴趣的项目、通过 AI 查找与总结分析，降低了解仓库的时间成本。

| 项目 | 用户决定 | 开发处理 |
| --- | --- | --- |
| 空 AI 分析字段 | 没有内容不显示 | 隐藏缺失、空值与纯未知占位，整组为空时隐藏标题；保留有意义的 0/false 和负面事实 |
| 仓库筛选 | 保留搜索、分类和排序；移除高级及保存筛选入口 | 移除仓库高级面板和设置中的保存筛选管理；历史 metadata 保留用于备份兼容 |
| AI 整理 | 删除手机入口；保留分析、总结、问答 | 移除生成整理的模式及表单；已有后台任务/建议仍可查看 |
| 版本发布 | 删除手机页签，需要时打开 GitHub | 移除移动 Release 读取/订阅/已读入口；同步资料与桌面能力保留 |
| AI 工作台 | 完整保留，只调整布局 | 保留项目、需求、候选、比较及提案；收起模型选择，减少重复标题和编辑入口 |
| X、Telegram、代码搜索 | 删除手机入口与来源管理 | 已移除；保留桌面配置和同步记录 |

全部 25 项决定现已完成，最终范围见 [手机阅读与发现优先改造方案](mobile-simplification-plan.md)，实施与发布状态见 [交付记录](mobile-simplification-delivery.md)。
