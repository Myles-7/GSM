## 入口记录纠正

早期分析与隔离验收把 `5174` 简写为“原桌面 origin”，不够准确。实际常用快捷方式已经改为生产 file-origin；5174 是另一套开发入口，并且各有独立 IDB 数据。该区别已通过快捷方式目标与备份副本数据库库存核实。本次保留两者，没有改端口来制造空 Store，也没有把开发数据搬迁覆盖常用数据。

历史隔离测试仍是有效功能证据，但不应改写成已经使用真实账号或原数据。真实数据升级及本机服务部署由本记录单独补充，付费 provider、真实远端 Star、远端 Vectorize 和人工系统保存对话框仍不冒充验收。
