# 手机 HTML 阅读打磨：需求确认记录

本轮依据用户的三张真机截图逐项确认，再制定开发与验证方案。仍保留离线 HTML、完整摘要、桌面主题及原阅读回传流程。

## 已确认

1. 期刊选择改为网页内底部面板。日常仅显示一行当前期刊日期与数量；面板内历史期刊的日期、数量、完成状态分列显示，替换系统原生 select。
2. 卡片只标记桌面已知“已 Star”的项目；未确认状态在详情说明。收藏候选与 GitHub 已 Star 分开，离线 HTML 不声称实时查询。
3. 详情阅读操作采用一行四等分轻量按钮条，小图标与“已读／兴趣／忽略／候选”同行，减少边框，保留选中状态及至少 44px 点击高度。
4. 已 Star 项目的候选位置改为只读“已 Star”，其余操作位置保持不变，不自动删除已有回传记录。
5. 顶部采用两行紧凑结构：主工具栏与当前频道／期刊／数量。频道改由抽屉切换，移除横滑快捷频道栏和重复标题；日期及说明收入更多菜单。
6. 阅读操作仍放正文末尾，不固定悬浮占用屏幕。
7. 笔记按需展开：无笔记显示“添加笔记”，已有笔记显示简短预览，点击后编辑。继续自动保存与导出回传。
8. 隐藏 0 项期刊，只在选择面板展示可阅读期刊；缺失日期与原因放入信息面板。有项目但未完成的期刊标为“部分内容”。
9. 详情顶部只显示项目名并单行省略，完整所属者／项目名放在详情信息中，可查看与复制。

## 开发与验证方案

先调整顶部和详情标题，再替换期刊选择器、补齐 Star 展示，最后打磨操作条与笔记。针对原代码新增失败回归用例后实施；保留 v1／v2 回传及稳定期刊 ID，隐藏期刊不删除历史和回执。

Star 正向状态仅依据生成时当前账户的桌面收藏记录；不在收藏记录中不能推断未 Star，详情说明未知。此轮不为状态增加 GitHub 网络调用，也不改变 Star 操作权限。

顶部采用两个至少 44px 的操作行，去掉重复标题和大面积强调色导出按钮；安全区按真实浏览器环境保留一次，不修改手机系统状态栏。完整摘要和分析内容、默认 16px 正文字号、邮件配置、正文末尾操作的位置均保留。

验证实际生成的独立 HTML，覆盖 360／390／430／768／1024px、明暗、20px 阅读字号、单行按钮及横向溢出、空与全部空期刊、频道状态与返回、笔记重开和导出。另回归 5,000 仓库窗口渲染、旧回传格式、生成器内容筛选和 Electron 邮件保护。
