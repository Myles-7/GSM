# GSM 手机阅读与发现优先改造方案

用户经逐项询问确认本方案；只移除手机入口，不清除既有同步记录或桌面能力。沿用当前应用 ID、签名、凭据和离线队列。

## 确认的范围

| 功能 | 最终决定 |
| --- | --- |
| 仓库筛选 | 只保留搜索、分类和排序；移除高级筛选、保存筛选入口 |
| AI 整理/分类建议 | 删除手机生成入口，保留人工分类和批量编辑 |
| 仓库版本页签 | 删除；需要时打开 GitHub |
| 完整工作台 | 保留项目、需求、候选、比较、提案，仅优化布局 |
| X、Telegram、代码搜索 | 删除手机频道及对应来源管理入口 |
| 趋势历史 | 保留入口和自动快照 |
| 自定义频道 | 保留并增强填写要求、生成、阅读、历史和恢复流程 |
| 最近浏览 | 保留 |
| 仓库批量操作 | 全部保留，收进操作菜单；AI 分类建议除外 |
| 人工编辑 | 收进“编辑资料”面板，概览优先阅读 |
| 分析依据 | 默认折叠“查看依据”，仅来源链接和生成时间，不展示详细摘录 |
| 空分析字段 | 隐藏缺失、空内容和纯未知占位；整组为空时隐藏标题 |
| 阅读工具 | 只保留目录与字号，不展示查找和返回顶部 |
| 原始数据 | 普通页面移除原始 JSON，设置仍提供脱敏诊断导出 |
| 发现卡片 | 项目名、足够说明用途的多行摘要、少量标签、Star；完整分析进入详情 |
| 热门发布 | 实际 Release 内容、版本和发布时间，不以 pushed_at 代替 |
| 主题探索 | 保留，提供中文主题快捷入口 |
| 最受欢迎 | 保留成熟工具入口；增量加载更多，稳定列表、去重、保存位置继续阅读；主动刷新才更新列表 |
| 周刊 | 收进“更多”，不占常用频道 |
| 任务中心 | 顶部入口保留，只显示进行中数量；执行详情放任务中心 |
| 本机备份 | 设置“高级数据管理”中保留，非日常展示 |
| 发现 AI 操作 | 先进入详情阅读现有摘要，需要时再分析；加入研究仍为更多操作 |
| 仓库 AI 主动作 | 统一“AI 分析”，默认详情及摘要；重新分析放菜单 |

## 实施

1. 完成仓库阅读/编辑隔离、统一分析、操作菜单与移除项；读取旧资料不受影响。
2. 完成精简发现目录和卡片、完整详情、主题中文快捷、增强自定义频道。
3. 后端实现真实 Release 查询和稳定热门浏览会话；校验账户、固定请求参数、恢复加载与去重，明确 GitHub 上游限制，不宣传全量无上限。
4. 设置屏蔽手机已删除频道，但不覆盖删除桌面频道配置；阅读只留目录字号；任务原位只给进度/取消/结果入口，详细事件到任务中心。
5. 功能和数据回归、手机多尺寸与连续浏览检查、独立后端发布包验证、数据库备份后升级电脑服务、构建同身份 APK；记录真机未验收项。

## 验证重点

删除入口不可通过备用菜单重新生成；有效 AI 内容完整保留，缺失内容不占位；手机配置不删除电脑来源；浏览恢复定位正确，追加不重排已看列表；Release 必须有实际版本数据；离线修改、冲突、草稿与历史任务仍可恢复。
