## 三方差异及冲突原则（业务修改前记录）

1. 上游新增批量 Star 引用已删除的旧翻译模块，这是语义冲突；
   移除独立翻译状态和入口，由现有全页面翻译处理原始描述，不阻塞 Star。
2. Store normalizer、类型与 locale 都有双方修改；结构化保留新过滤器、
   频道约束、pageTranslationEnabled 以及旧翻译字段清理，版本保持 16。
3. 网络和同步采用目标标签完整实现，包括 API 工厂的 direct 例外、
   syncToBackend 布尔返回、显式失败报告和同步竞态保护。
4. CSP 合入上游精确来源，另加 https://edge.microsoft.com；
   不新增 wildcard 或 unsafe-eval。
5. package/lock 合并后保留固定 translate.js 和 dev:desktop/electron:dev。
6. Release 采用最终 includeRepos/alwaysExcludeRepos；丢弃 excludeRepos，
   不能把过渡版本字段解释为最终排除名单。跨过滤器 OR，单过滤器排除优先。
7. Electron 开发地址、脚本、图标和所有个人文档保留。

## 验证过程中的问题

- 第一轮前端测试缺少新共享按钮需要的 TooltipProvider，已修复测试包装；
  同时高并行导致 README 用例超时，限制为 4 workers 后完整重跑通过。
- Docker 首次 Alpine DNS 临时错误，原 Dockerfile 不变重试成功。
- Playwright 自动附加 Electron 时被开发模式自动打开的 DevTools 目标阻塞；
  仅在隔离测试 harness 中禁用自动打开 DevTools，使用 CDP 驱动真实桌面主程序，
  没有改动产品安全设置或业务代码。
- translate.js 未使用的 eval 代码仍有打包警告；CSP 没有 unsafe-eval，
  实际 Edge 翻译验收成功。在线服务可用性和译文质量不作保证。
- 外部 GitHub/AI 的 CSP 测试使用模拟响应，不代表对真实账号登录或付费 AI 调用的验收。
