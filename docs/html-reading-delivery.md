# 每日 HTML 功能交付与使用说明

更新日期：2026-10-03。最新一轮已完成阅读预设、分页面／频道配置、完整摘要、阅读视图和连续阅读；详见 [内容自定义与完整阅读记录](html-reading-customization-20261003.md)。下方历史验证表记录上一轮结果，本轮结果以新记录为准。

本轮改为继承桌面主题、紧凑卡片、独立频道与全屏详情，并增加v2继续阅读位置回传。最终构建、前端回归、桌面回归及隔离浏览器验证通过；用户当前运行程序仍需重新加载新构建。本轮没有配置真实Gmail授权、发送邮件或进行手机真机验证。新增功能、迁移和本轮结果见 [桌面风格改造记录](html-reading-redesign-20261003.md)。

## 从哪里使用

1. 使用包含本次改造的桌面版本。替换构建后，从托盘菜单退出 GSM，再使用原来的桌面快捷方式启动。只点窗口关闭可能仍在托盘运行，不等同于重启。
2. 打开桌面 **设置 → 每日 HTML**。
3. 按需选择仓库分类、频道、数量、字段和分析栏目。预览和手动导出采用当前表单；定时发送采用已保存设置。
4. 先点 **预览 HTML** 或 **导出 HTML** 检查内容，再点 **保存设置**。预览可切换五种宽度和明暗，并显示各频道／期刊条目数量及实际体积；预览使用隔离沙盒，提示不能本地保存属于预期，预览标记仅供体验。
5. 在“Gmail 与每日发送”填发件地址、收件地址和 Google 应用专用密码，点 **保存加密授权**、**测试连接（不发邮件）**。
6. 需要启用自动发送时勾选 **启用每日邮件**，保留默认北京时间 08:00，然后保存。也可以先 **立即生成并发送** 做实际附件验证。

首次安装默认没有邮箱授权，自动发送关闭。本轮没有代填密码或发邮件。

Google 应用专用密码需开启两步验证，部分组织、安全密钥专用或高级保护账户不能创建；这不是普通登录密码。依据：[Google 应用专用密码说明](https://support.google.com/accounts/answer/185833)。Gmail SMTP 需要电脑网络能访问 smtp.gmail.com:465，Nodemailer 的 TCP 连接不使用桌面 Electron 的 HTTP 会话代理；请以设置里的连接测试判断本机可用性。

## 可以控制什么

| 区域 | 配置 |
|---|---|
| 仓库 | 启用／隐藏页面、选择分类或全部、数量上限、Star／更新时间／名称排序、未读筛选、忽略过滤 |
| 发现 | 每频道数量、历史期数与内容覆盖；选择趋势、最受欢迎、热门发布、主题、搜索缓存与已有自定义频道；内置频道每频道限额，自定义频道每期独立限额，保留历史日期切换 |
| 卡片与内容 | AI 摘要、原始描述、标签、分类、语言、Star、更新日期、已有阅读笔记、推荐理由；卡片呈现精简内容，其余进入详情 |
| 详情 | 已有分析中的问题、功能、场景、架构、快速开始、部署、成本、维护，展开／折叠／不导出及分区内顺序 |
| 依据与版本 | 来源链接和分析时间、已缓存的真实版本说明；不存在的内容隐藏 |
| 样式 | 继承桌面主题／强调色／圆角；卡片与详情完整摘要，跟随桌面／手机系统／浅／深明暗模式、14／16／18／20px字号、紧凑／标准密度、初始页面 |
| 文件 | 1–15 MB 上限；超限明确失败并要求减少内容，不悄悄截断项目 |
| 手机操作 | 已读、兴趣／忽略、笔记、收藏候选，各自开关 |
| 每日流程 | 启用、北京时间、发送前更新内置频道、等待已有自定义更新、手动发送、状态记录 |

选择“不导出”且卡片与其他视图不包含该字段时，会从打包载荷中裁剪，分类关闭时也不保留分类ID。关闭所有修改权限时不显示空编辑面板。私有的阅读笔记默认不邮件发送，用户可主动开启。个人项目说明不导出；已有AI摘要优先，缺失时使用允许导出的原始描述。

手机采用底部单行“仓库／发现”、顶部搜索按钮与导出。搜索点击展开，收起保留条件；明暗切换及完整频道说明、更新时间在信息面板中。点击卡片进入全屏“概览／使用／维护”，只保留一次完整仓库标题，缺失栏目不显示；列表与命令保留结构，来源和生成时间默认折叠。每批40项、最多同时挂载120张卡片；同一项目的数据只打包一份，各频道和期刊保存引用。后续留白调整的对比、验证和旧附件使用说明见[手机阅读留白优化](html-reading-spacing-20261003.md)。

发现内容如实来自桌面：内置频道是当前运行会话已加载结果，发送前可刷新；自定义频道来自实际 IndexedDB 的已有期刊及分析。桌面“热门发布”已核验真实 Release，HTML 优先使用频道内的发布资料，显示标签、实际发布日期及已缓存标题或说明；缺少有效发布资料的旧缓存提示需要刷新，不把推送时间当成 Release 发布时间。导出本身不新增联网或 AI 请求。

分析读取桌面同账户的共享分析资产，保持语言优先与已有结果回退规则。模型切换不让已保存结果消失，删除屏障阻止旧缓存恢复人工删除的分析。本流程不会生成新的模型调用，保持桌面已有频道和 AGY 的原运行行为。可最多等待正在执行的自定义发现更新 60 秒，不启动新研究。内置频道单项 30 秒、总共 90 秒；失败仍可发送当前可用缓存，警告同时进入邮件与 HTML，更新时间保持原值。缓存超过24小时、缓存缺失和筛选后为空分别提示。

08:00 是开始更新时间，不是保证收件时间。GSM 需运行，电脑需醒着。恢复运行后只检查当天；失败、中断或 SMTP 结果不确定不会反复自动发送，需先查邮件再手动处理。

## 手机上怎样带回修改

下载邮件附件，用能运行本地 HTML 脚本的浏览器打开。邮箱预览、部分文件查看器可能只能阅读，不支持按钮。

卡片直接标记感兴趣／收藏候选；打开详情时自动已读（须开启已读权限），详情中可以改回未读、忽略或填写笔记。点顶部 **导出**，复制文本；复制不可用时手动选择文本，或下载 JSON。导出同时携带阅读位置，即使没有业务修改也可以回传。关闭前确认已导出，浏览器本地存储只作为便利功能。

电脑回到 **设置 → 每日 HTML → 导入手机阅读记录**，粘贴或选 JSON，点击 **预览回传修改**。核对业务修改及“继续阅读位置”，有冲突时逐项选择手机或电脑版本，然后确认导入。重复操作会跳过，旧快照的位置不覆盖较新位置；预览后电脑记录又变化则要求重新预览。桌面仍接收旧v1回传，新HTML使用v2。

“阅读记录与收藏候选”可查阅、编辑笔记和处理候选。导入不会自动 Star；**确认 Star** 还需明确确认，并核对 GitHub 数字项目 ID。已收藏项目原有 AI 分析和笔记不会被这一步替换。

阅读状态和笔记是本机的独立阅读记录，用于后续 HTML，不自动修改人工分类、模型选择或桌面原始项目说明。未回传的修改和位置无法进入下一天文件。已回传后，新文件优先定位同频道的稳定项目；项目或期刊缺失时定位附近可用项目或该频道最新一期，并提示。每日顺序跟随当天桌面快照。旧包需在生成它的原电脑账户导入；恢复到手机时只可载入原 HTML，不把包直接套到新快照。

## 数据位置与清理结果

- 设置、阅读记录、回传去重、快照基础值和继续阅读位置：现有桌面浏览器资料中的IndexedDB `gsm-html-reading`，按GitHub数字账户分开。数据库v2首次迁移旧账户时，在`migration-backups`保存一次原始副本；副本与新资料同事务提交，失败回滚。不要删除当前桌面资料目录；没有新增跨电脑备份恢复入口。
- 邮箱授权：Electron userData/html-reading/gmail.enc，使用系统 safeStorage 加密。状态接口不返回授权码；不进入 HTML 或业务同步。
- 邮件状态及发送过的 HTML：同目录 delivery.json 与本机 HTML 存档。SMTP 被接受不保证收件箱送达，以收件箱为准。
- Android、Capacitor、移动页面、入口、专属构建／CI、测试工具以及旧移动输出已移出活动工程。恢复副本：output/retired-mobile-20260930。没有清空用户资料，也没有卸载桌面依赖的共享后端。
- 当前安装在手机上的旧 APK 不会被电脑源码清理自动卸载；旧 APK 的离线队列也不会自动转成新 HTML 回传格式。

日报运行在桌面，不依赖以前的 Windows 手机服务升级或 Tailscale。没有继续被取消的 UAC 升级。
